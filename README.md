`TypeScript` `Node.js` `Firebase` `Firestore` `OCR` `REST API`

### 🌀 maze-runner
![Status](https://img.shields.io/badge/Status-Shipped-2ea44f?style=flat-square)

`TypeScript` `Babylon.js` `WebGL`

### 📈 PMS Intelligence & Overdue Work Risk Analysis
![Status](https://img.shields.io/badge/Status-Research%20Complete-2ea44f?style=flat-square)

An ML system exploring whether performance-management data can predict tasks at risk of becoming overdue — with leakage prevention and time-based validation built in from the start.

**Approach:** database quality analysis → feature engineering → point-in-time safe datasets → gradient boosted classification

✅ Built for early intervention & planning support &nbsp;·&nbsp; ❌ Not intended for employee ranking or disciplinary decisions

`Python` `scikit-learn` `Pandas`
